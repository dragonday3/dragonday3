## `threat model mindset`

```
1. RECONNAISSANCE     →  What can an attacker see?
2. WEAPONIZATION      →  What exploits exist for the surface?
3. DELIVERY           →  How does the payload reach the target?
4. EXPLOITATION       →  Where does execution occur?
5. PERSISTENCE        →  How does an attacker stay?
6. LATERAL MOVEMENT   →  What else is reachable?
7. EXFILTRATION       →  What leaves the network?

Build the attack chain. Then break every link.
```
